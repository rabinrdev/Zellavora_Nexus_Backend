# Frontend API guide

_Generated by `npm run docs:artifacts` from the live OpenAPI document. Do not edit by hand; change the route definitions or `src/modules/*/docs.ts`._

API version **1.0.0** · 431 operations · base path `/api/v1` · interactive docs at `/api/docs` and `/api/redoc` (non-production).

## How to use this guide
1. Read **Getting started** (the description at the top of Swagger UI / `docs/openapi.yaml`) once: login, tenancy, pagination, idempotency, errors.
2. Find your module below. Every operation name (`operationId`) is also the method name in the typed client (`sdk/`), e.g. `api.createProject(...)`.
3. For each screen call `getMyPermissions` once and hide actions the user lacks.

## Auth flow
```
POST /auth/login            -> accessToken (15 min) + refreshToken        [loginWithPassword]
  401 mfa_required          -> repeat login with mfaCode
GET  /auth/me               -> user, organizations, permissions           [getCurrentUser]
POST /auth/refresh          -> new accessToken AND new refreshToken       [refreshAccessToken]
POST /auth/switch-organization -> token for another organization         [switchOrganization]
POST /auth/logout           -> revoke this session                        [logoutCurrentSession]
```

## Pagination walk-through
```
GET /projects?limit=2            -> { data: [p1, p2], meta: { limit: 2, nextCursor: "eyJ2…" } }
GET /projects?limit=2&cursor=eyJ2… -> { data: [p3], meta: { limit: 2, nextCursor: null } }   // last page
```

## Idempotency walk-through
```
POST /invoices/{invoiceId}/send   Idempotency-Key: 7b1c…   -> 200 { number: "INV-2026-0001" }
POST /invoices/{invoiceId}/send   Idempotency-Key: 7b1c…   -> 200 same body, header Idempotent-Replay: true
POST /invoices/{otherId}/send     Idempotency-Key: 7b1c…   -> 422 IDEMPOTENCY_KEY_REUSED
```

## Error codes
| Code | HTTP | Meaning | Frontend handling |
|---|---|---|---|
| `UNAUTHENTICATED` | 401 | Missing, expired or revoked credentials. | Try POST /auth/refresh once; if that fails send the user to the sign-in screen. |
| `FORBIDDEN` | 403 | Authenticated but not allowed (missing permission, read-only support session, no active organization). | Hide the action using GET /me/permissions; show a "you do not have access" message. |
| `TENANT_SUSPENDED` | 403 | The active organization is suspended. | Show a suspended-organization screen; only platform admins can reactivate. |
| `NOT_FOUND` | 404 | Resource does not exist, belongs to another organization, or its module is disabled. | Show a not-found state. Never retry. |
| `CONFLICT` | 409 | Uniqueness or state conflict, or a request with the same Idempotency-Key is still running. | Show the message; for in-flight idempotency retry after a short delay with the same key. |
| `PRECONDITION_FAILED` | 412 | If-Match / rowVersion is missing or stale: someone else changed the record. | Reload the record, show a merge/overwrite prompt, resend with the new rowVersion. |
| `VALIDATION_FAILED` | 422 | Body, query or path parameters failed validation; `details` lists each field. | Map `details[].field` to form fields and show `details[].issue` inline. |
| `IDEMPOTENCY_KEY_REUSED` | 422 | The Idempotency-Key was already used with a different request. | Generate a new key per distinct operation. |
| `PLAN_LIMIT_EXCEEDED` | 402 | The subscription plan does not include this feature or its quota is exhausted. | Show an upgrade prompt using GET /entitlements/{entitlementKey}. |
| `RATE_LIMITED` | 429 | Too many requests; `Retry-After` gives the seconds to wait. | Back off for Retry-After seconds, then retry. |
| `MAINTENANCE` | 503 | The service is in maintenance mode; `Retry-After` is set. | Show a maintenance banner and poll GET /health/ready. |
| `INTERNAL` | 500 | Unexpected server error. `requestId` identifies it in the logs. | Show a generic error with the requestId so support can trace it. |
